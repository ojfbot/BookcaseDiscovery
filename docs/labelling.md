# Labelling tool: Label Studio spike (V-1a)

Card V-1a asks whether Label Studio is the labelling tool (adopt) or whether V-1b builds a custom one. This page records what was checked, with numbers, and what is still open. Label format: [labels.md](labels.md).

**Status: trial done 2026-11-02. Verdict: not adopted; no hand labelling (OC36).** The agent-labelling clause of the decision rule was not measured as written (see [Decision rule](#decision-rule)).

## Run it

One-time install (owner-approved, checklist #6), into Label Studio's own `uv` environment:

```bash
uv tool install --python 3.12 label-studio
```

```bash
scripts/label-studio.sh start
```

`start` generates a local login on first run (`$BOOKCASE_DATA/labels/ls-credentials.txt`, mode 600, never committed or pasted anywhere) and serves on `http://127.0.0.1:8088` (`LS_PORT` changes it). A project is made from `docs/labelling-config.xml`, with images allowed from one directory under `$BOOKCASE_DATA`:

```bash
scripts/label-studio.sh project "<title>" <tasks.json> <images-dir>
```

A task is `{"data": {"image": "/data/local-files/?d=<path relative to $BOOKCASE_DATA>", "hash": "<sha256>", "setting": "shelf-48", "shelfIndex": 0, "width": W, "height": H}}`. Export a project (Export → JSON), then:

```bash
pnpm labels:import <export.json> --session <id>
```

The synthetic test shelf is generated, not photographed (`scripts/synthetic-shelf.py`, run with Label Studio's own Python, which ships Pillow and numpy; it is the one Python script outside `helpers/`, see `implementation-notes.md`).

## No data leaves the machine

Label Studio 1.23.2 does **not** do this by default. Read from its source and confirmed by running it:

| Default | What it does | Switched off by |
|---|---|---|
| binds `0.0.0.0` | reachable from the network | `--internal-host 127.0.0.1` (`lsof` shows only `127.0.0.1:8088` listening) |
| Sentry DSNs set (back end and front end) | error reports to sentry.io | `SENTRY_DSN=` and `FRONTEND_SENTRY_DSN=` (empty) |
| `COLLECT_ANALYTICS` on | usage events | `COLLECT_ANALYTICS=false` |
| `LATEST_VERSION_CHECK` on | asks PyPI for the newest version | `LATEST_VERSION_CHECK=false` |
| sign-up open | anyone who can reach it | `LABEL_STUDIO_DISABLE_SIGNUP_WITHOUT_LINK=true` |
| local files served only if enabled | images under a directory | `LOCAL_FILES_SERVING_ENABLED=true`, `LOCAL_FILES_DOCUMENT_ROOT=$BOOKCASE_DATA`, plus a per-project Local Files storage limited to the images directory |

`scripts/label-studio.sh start` sets all of these. With them set, during a session of loading, labelling, exporting and importing: the browser requested only `127.0.0.1:8088`, and the server held no connection to a non-loopback address. (The login page shows a promotional link to humansignal.com; it is a link, not a request.) The database, login and tasks live in `$BOOKCASE_DATA/labels/ls-data/`. No cloud storage was configured.

Label Studio only serves `/data/local-files/` for files under a Local Files storage of the project, so a project can read only its `images-dir`. Note that the request is authenticated by browser session, not by API token.

## What was checked

Synthetic 20-spine shelf: 8064 × 6048 (48.8 MP), 11.5 MB JPEG with noise, shelf tilted 3°, vertical titles and authors, generated by `scripts/synthetic-shelf.py` (seed 1). Browser: the in-app browser pane at 1500 × 950, Label Studio and its browser on the same Mac. These are single runs, not a benchmark.

| Check | Result |
|---|---|
| 48 MP image load | The file transfers in about 15 ms and a fresh decode takes about 130 ms. Opening a task cold shows the image after roughly 10–15 s (watched three times, not instrumented); switching to another annotation tab on the same task blanks the image for about 8 s while it re-renders. Memory stayed small (JS heap about 25 MB, the image is decoded by the browser). **This is the slowest part of the tool.** Serving a downscaled copy to the tool is possible, see Observations. |
| Zoom | Toolbar zoom in, out and fit work (`shift+1` fits; zoom in is `⌘ +`). Ctrl-wheel did not zoom in this browser. Frame time while zooming was 33 ms, with no longer frames (the pane caps at about 30 fps). The image is the full 48 MP bitmap, so zoomed-in detail is real pixels. |
| Rotated boxes | `RectangleLabels` boxes are drawn axis-aligned and then rotated by a handle on the box, or by typing the rotation into the region's Info panel (X, Y, W, H and rotation are all editable there). Rotation is about the top-left corner, in degrees clockwise, with sizes in percent of the image. The converter's geometry matches: boxes posted from the generator's ground truth lay on the tilted spines in the editor, and export → import reproduced the ground-truth corners to within 0.08 px. **Each rotated box costs one extra step** over a plain box. |
| Keyboard flow title → author → next | Label hotkeys work: `1` spine, `2` face-out, `3` stacked, `4` not-a-book, `5` shelf-band. `Escape` deselects, and it is needed: with a region selected, a drag that starts inside it moves it instead of drawing. A per-region text field takes Enter to submit its entry. After that, Tab moved focus to the entry's delete button and a `hotkey="a"` on the author field did not focus it, so **author needs a mouse click** (title → author → next is not a pure keyboard flow). An autosaved draft survives a reload. |
| Export → converter | `pnpm labels:import` turns a Label Studio JSON export into the schema; `pnpm test` round-trips it (export → schema → Label Studio → schema, and schema → Label Studio → schema). The fixture `test/fixtures/synthetic/labelstudio-export-shelf.json` is a real export of the synthetic shelf from this Label Studio version, with 20 spines (one `unreadable`, one `face-out` with a note, one `not-a-book`, one with a series) and one shelf band. The annotation in that fixture was posted through the API from the generator's ground truth, **not drawn by hand in the editor**. |
| Reads and writes only under `$BOOKCASE_DATA/labels/` | Yes: the database is `labels/ls-data/`, served images must be under the storage's directory, and `labels:import` writes only `labels/<session>.json` (a session id with `/` or `..` is refused; a test covers it). |

## Observations for F-0 (OC34: pre-annotations and the review queue)

Checked through the API with the synthetic shelf; the ML-backend route was not tried.

- **Pre-annotations import.** Tasks imported with a `predictions` entry carry the same result format as an annotation (rotated `rectanglelabels` with `title`/`author`/`flags` text per region). 61 results on one task imported and were returned by the API. `toLabelStudio` already writes that format.
- **Uncertainty-ordered queue works per task.** With the project's sampling set to `Uncertainty sampling`, `Label All Tasks` served tasks in ascending prediction `score`: 0.2, then 0.5, then 0.9. The score is **per task (photo)**, not per spine.
- **Consequence for F-0.** To order spines rather than photos, F-0 can make one task per flagged crop or per photo of flagged spines (the box percentages stay valid; the converter takes the original size from the task's `width` and `height`). Per-region `score` in a result was not tested for ordering. The random 10 % spot-check can be mixed into the queue as extra tasks with mid scores.
- **Downscaled working copies are viable.** Boxes are stored in percent, so labels made on a 12 MP copy map back to the 48 MP original exactly when the task `width` and `height` are the original's. That would remove the 10–15 s open time. Not tried with a real photo.
- **Accepting a prediction** was exercised by posting it as an annotation (what Accept does); the editor's rendering of a prediction was not looked at, only of an annotation in the same format.

## Decision rule

Pre-registered on the card: adopt if a synthetic 20-spine shelf can be labelled in ≤25 minutes by the agent **and** the owner's 10-minute trial raises no blocker; otherwise dispatch V-1b.

- **Agent clause: not measured as written.** The agent has no keyboard or mouse; it drives the editor through synthetic pointer events, and that route was unreliable (a drag that started inside a selected box moved it instead; some drags registered late, so a later click extended them). Roughly 9 actions per spine (hotkey, drag, click title, type, Enter, click author, type, Enter, plus the rotation step) were needed by hand in the editor. A whole-shelf run was not completed, so there is no honest wall-clock number. This is a limit of the driver, not evidence about the tool. It is recorded as a deviation.
- **Owner clause: pending.** See the trial below.
- **Technical gate, met:** 48 MP loads and zooms; rotated rectangles and their geometry are verified; export converts losslessly; nothing leaves the machine once the defaults above are changed; pre-annotations and an uncertainty queue exist.
- **Known friction to judge in the trial:** the 10–15 s cold open of a 48 MP photo, one extra step per rotated box, and a mouse click between title and author.

Recommendation: let the owner's trial decide. If the owner's labelling pace on the synthetic shelf is acceptable, adopt. If the open time or the per-spine clicks are a blocker, dispatch V-1b; the schema, converter and test fixture carry over either way.

## Owner trial (checklist #2, 10 minutes)

Project **V-1a owner trial (synthetic shelf)** holds the 48 MP synthetic shelf with 20 fake spines (invented titles and authors; read them off the image).

1. `scripts/label-studio.sh start`, then open `http://127.0.0.1:8088`. The login is in `$BOOKCASE_DATA/labels/ls-credentials.txt`.
2. Open the project and press **Label All Tasks**.
3. Label as many of the 20 spines as you can in 10 minutes: press `1`, drag a box over a spine, rotate it to the tilt (handle, or type the rotation in the right-hand panel), type the title, press Enter, click the author field, type, press Enter. Try `U` for an unreadable spine, `4` for not-a-book, and `5` to draw the shelf band. Zoom as you like.
4. Note how many spines you finished, what slowed you, and anything that would stop you doing 30–60 spines in a sitting.
5. Optional: Submit, Export → JSON, `pnpm labels:import <file> --session v1a-trial`.

**Verdict (owner, 2026-11-02): not adopted. No hand labelling (OC36).** The owner ran the trial from a laptop over the LAN and stopped: drawing rotated boxes and typing titles is very tedious and not worth their time. The agent-timing clause was waived by the owner beforehand. Label Studio is not adopted and V-1b is not built. The label schema (`src/eval/labels.ts`) and converter stay, for importing a public yardstick dataset and machine labels.
