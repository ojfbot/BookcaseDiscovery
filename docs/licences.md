# Licence check (C-0)

Checked 2026-11-02 by card C-0 (`claude/c-0-licences-2a30cf`). Question: may the MVP index each source locally, and may it be redistributed later? The repo is **AGPL-3.0** (`LICENSE`; G-LIC ruled 2026-10-31), so "redistribution OK?" is answered against AGPL-3.0.

**Method.** Each page was read with web-fetch (HTML or raw text only). No accounts, no downloads, no contact with anyone. Quotes are 15 words or fewer and are copied from the fetched text. A source that could not be fetched is marked **UNVERIFIED**; no licence text was filled in from memory. Where a row relies on another card's branch or a search snippet, the row says so. The readings in the "OK?" columns are the card's reading of those texts, not legal advice.

## Flags for the conductor

- **Local indexing not OK: Open Library cover images.** The covers API says it is "intended for displaying covers … and not for bulk download." The MVP indexes ISFDB only (OC20), so no MVP blocker follows. Covers must not be committed.
- **Not verified, MVP-critical: ISFDB.** Every isfdb.org fetch returned HTTP 403 (both `www.` and bare host, plus the wiki pages). The CC BY 4.0 reading comes from C-R's fetch of the home page and from a search snippet of the wiki. It is not re-verified here. **Local indexing is provisionally yes.** No source read says otherwise. A browser check of the ISFDB licence page before the first index build would close this.
- **Borderline: Roboflow `open-shelves` is CC BY-NC-SA 4.0.** Its non-commercial term conflicts with redistribution inside an AGPL-3.0 repo (AGPL-3.0 §10 bars further restrictions on the rights it grants). The MVP does not need it. Conductor to rule if it is ever wanted.
- **Not established: IEEE DataPort shelf-spine dataset.** No licence is stated on the fetched page, and access needs a subscription. Treated as no redistribution until a grant is shown.
